# HR Analytics Employee Attrition Dashboard

An interactive **HR Analytics Dashboard** built using **Microsoft Power BI** to analyze employee attrition, workforce trends, and factors influencing employee turnover.

### 📊 Key KPIs

* Total Employees
* Active Employees
* Attrition Count & Rate
* Retention Rate
* Average Monthly Income

### 🔍 Dashboard Analysis

The dashboard explores attrition across **Department, Job Role, Gender, Age Group, Salary Slab, Overtime, Education Field, and Job Satisfaction**, with interactive slicers for dynamic analysis.

### 💡 Key Insights

* Overtime employees show higher attrition.
* Lower salary groups experience greater turnover.
* Attrition differs across departments, roles, and age groups.
* Job satisfaction significantly influences employee retention.

### 🛠 Tools & Technologies

**Power BI | Power Query | DAX | Data Modeling | Data Visualization**

### 🚀 Future Scope

Machine learning-based attrition prediction, drill-through analysis, executive reports, and live HR database integration.
